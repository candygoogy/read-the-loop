Read the Loop

AI 编程智能体到底是怎样工作的？我们录下了真实的会话，你可以一步一步地看。

章节

  1. 第一章

    智能体就是一个循环

    模型只会读文本、写文本。看一次真实的会话怎样修好一个小游戏里的 bug，一轮接一轮，而它从头到尾都看不到这个游戏。

    从这里开始
  2. 第二章

    上下文窗口

    模型每次调用要读多少内容，在一次真实的会话里，这些加起来又有多少。

    阅读
  3. 第三章

    缓存

    把整段对话再读一遍，为什么花不了多少钱，又是什么会让缓存失效。

    阅读

接下来的章节

  1. 第四章 · 即将推出

    压缩

    对话被压缩成一份摘要时会发生什么，之后智能体还知道些什么。

  2. 第五章 · 即将推出

    工具与权限

    模型从每个工具的说明里得知了什么，又是谁决定什么可以运行。

  3. 第六章 · 即将推出

    子智能体

    为一个支线任务另开一段全新的对话，以及从那里带回来的东西。

  4. 第七章 · 即将推出

    失败模式

    原地打转、凭空捏造的函数、谎报的“完成”、破坏性命令：真实发生过的案例，以及我们录下来、想要抓住它们的运行。

  5. 第八章 · 即将推出

    自己动手做一个智能体

    一个能在浏览器里运行的小智能体，背后的模型由一段录制重放。

关于本站

Read the Loop 是用 Claude Code 做的，展示的也是 Claude Code 工作时的录制：它运行的命令、传回来的结果、模型自己写的话，以及每一个数字，都读取自这些录制。只有讲解是人写的。
