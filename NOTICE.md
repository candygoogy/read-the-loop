## Claude Code

Every recording on this site is a session of [Claude Code](https://claude.com/claude-code), Anthropic's coding
agent, run with `claude -p` and recorded as it ran. The site itself was also made with Claude Code. The
recordings show what the tool did in these sessions; the site makes no other claim about how it is built.
